# Ascend — Anime / Isekai RPG Minecraft Mod

[![Minecraft](https://img.shields.io/badge/Minecraft-1.20.1-blue.svg)](https://www.minecraft.net/)
[![Fabric](https://img.shields.io/badge/Modloader-Fabric-orange.svg)](https://fabricmc.net/)

**Ascend** is an anime and isekai inspired RPG mod for Minecraft Java Edition. Reborn into the Minecraft world, players choose their race, class, and signature skills, progress through a *Solo Leveling* inspired status screen, unlock directional combat dodges, clear ranked dungeons, and battle multi-phase bosses.

---

## 🌟 Features
- **4-Step Character Creation**: Set world difficulty, choose your race (Human, Dragonoid, Slime), class (Swordsman, Summoner, Mage, Archer, Tank), and starting skills.
- **Solo Leveling Status System (`K`)**: Upgrade Strength, Speed, Vitality, Mana, and Defense using **Essence** (mod XP separate from vanilla XP).
- **Anime Action Combat**: Directional dashes with invincibility frames (i-frames), stamina and mana resource meters.
- **Custom Skills & Minions**: Active spellcasting, ranged abilities, and minions that follow and protect you.
- **Dungeons & Boss Encounters**: Procedurally assembled ranked dungeons (E to S rank) culminating in epic boss battles.

---

## 🛠️ Building & Running

### Requirements
- **Java 17 or higher** (JDK 17 or JDK 21/22)

### Run in Development
```bash
./gradlew runClient
```
*(On Windows: `.\gradlew.bat runClient`)*

### Build Mod Jar
```bash
./gradlew build
```
The compiled jar will be available in `build/libs/`.
